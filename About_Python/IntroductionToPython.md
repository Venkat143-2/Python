# Definition of Python

**Python is a high-level, interpreted, object-oriented, functional, procedural, dynamically typed, and general-purpose programming language.**

It is easy to learn because it has a simple and readable syntax. Python allows developers to build almost anything, including websites, AI applications, automation tools, games, and data science applications.

Python was created with the philosophy:

> "Code should be easy to read and write."

This philosophy focuses on making programs simple, clean, and understandable.

# Breaking Down the Definition

Python is a **high-level programming language**, which means its syntax is close to human language and easy for programmers to understand.

A programmer does not need to worry about low-level computer details such as:

- CPU instructions
- Hardware operations

## 2. Interpreted Language

The execution process:

```
Python Code (.py)
        |
        ▼
Python Interpreter
        |
        ▼
Output
```

Unlike compiled languages, Python does not require a separate compilation step before running.

However, internally Python converts source code into bytecode before execution.

The process:

```
Python Source Code
        |
        ▼
Bytecode
        |
        ▼
Python Virtual Machine
        |
        ▼
Machine Instructions
```

# Why is Python Slower Than Other Languages?

Python is slower than languages like **C, C++, and Rust** because Python focuses more on:

- Simplicity
- Readability
- Developer productivity
- Flexibility

rather than maximum execution speed.

The main reason:

> **Python is slower because it is an interpreted, dynamically typed language that performs many operations at runtime instead of before execution.**

---

# 1. Python is an Interpreted Language

Python code is not directly converted into machine code before execution.

Instead, Python uses an interpreter to execute the program.

The execution process:

```
Python Code (.py)
        |
        ▼
Python Interpreter (CPython)
        |
        ▼
Bytecode
        |
        ▼
Python Virtual Machine
        |
        ▼
Machine Instructions
```

Every instruction passes through the interpreter, which adds extra processing time.

---

## Comparison with Compiled Languages

Languages like C follow this process:

```
C Code
   |
   ▼
Compiler
   |
   ▼
Machine Code
   |
   ▼
CPU
```

The CPU directly executes machine code, making execution faster.

---

# 2. Dynamic Typing Requires Runtime Checks

Python is dynamically typed.

This means Python determines variable types during execution.

Example:

```python
a = 10
b = 20

c = a + b
```

Before performing addition, Python needs to check:

- What type is `a`?
- What type is `b`?
- Is `+` valid for these types?

These checks happen every time the program runs.

---

## Comparison with C

In C:

```c
int a = 10;
int b = 20;

int c = a + b;
```

The compiler already knows:

```
a → integer
b → integer
+ → integer addition
```

No additional checking is needed during execution.

---

# 3. Everything in Python is an Object

In Python, even simple values are objects.

Example:

```python
x = 5
```

The number `5` is an integer object.

It contains:

- Value
- Type information
- Reference count
- Other object information

---

In C:

```c
int x = 5;
```

The integer is simply stored as a fixed-size value in memory.

Python objects require more memory and processing, which affects speed.

---

# 4. Function Calls Have More Overhead

Every function call in Python requires additional work:

- Creating a function call frame
- Looking up the function
- Handling arguments
- Managing namespaces
- Returning objects

Compiled languages can optimize function calls more aggressively.

---

# 5. Variable Lookup Takes More Time

When Python sees:

```python
print(x)
```

It searches for `x` in different places:

1. Local scope
2. Enclosing scope
3. Global scope
4. Built-in scope

This lookup process takes extra time.

Compiled languages usually know variable locations before execution.

---

# 6. Automatic Memory Management

Python manages memory automatically using:

- Reference counting
- Garbage collection

This makes programming easier but requires additional processing.

Languages like C allow programmers to manage memory manually.

---

# 7. Fewer Compile-Time Optimizations

Languages like C and C++ perform many optimizations before execution.

Examples:

- Function inlining
- Loop optimization
- Dead code elimination
- Register optimization

Python performs fewer optimizations because code is executed dynamically.

---

# Example Comparison

## C

```c
int sum = a + b;
```

The compiler creates efficient machine instructions.

---

## Python

```python
sum = a + b
```

Python needs to:

1. Find variable `a`
2. Find variable `b`
3. Check their types
4. Find the correct addition operation
5. Create the result object
6. Store the result

All these extra steps reduce speed.

---

# Why Everything is an Object in Python?

In Python, the statement:

> "Everything is an object"

means that every value, data type, function, class, and module is represented as an object.

Every object has:

## 1. Identity

A unique location in memory.

Example:

```python
x = 10
```

The object `10` has its own identity.

---

## 2. Type

Defines what kind of object it is.

Example:

```python
x = 10

print(type(x))
```

Output:

```
<class 'int'>
```

---

## 3. Value

The actual data stored inside the object.

Example:

```python
name = "Python"
```

Value:

```
Python
```

---

## 4. Behavior

Operations that can be performed on the object.

Example:

```python
name = "python"

print(name.upper())
```

Output:

```
PYTHON
```

The string object provides the `upper()` method.

---

# How Python Stores Objects

When we write:

```python
x = 10
```

Python creates an integer object.

The variable `x` stores a reference to that object.

Memory representation:

```
        x
        |
        ▼
   +---------+
   |   int   |
   | value:10|
   +---------+
```

---

# Variables Store References

Python variables do not directly store values.

Example:

```python
a = 100
b = a
```

Memory:

```
       a
       |
       ▼
    +------+
    | 100  |
    +------+
       ▲
       |
       b
```

Both variables refer to the same object.
