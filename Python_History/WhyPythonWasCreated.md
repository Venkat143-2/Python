# Why Python Was Created?

Python was created mainly because **Guido van Rossum wanted a programming language that was easier to use, easier to read, and powerful enough for real-world programming**.

Let's understand the story rather than just memorizing the answer.

### The situation before Python

In the late 1980s, programmers already had languages such as **C, C++**, and others.

These languages were powerful, but writing programs could require a lot of code and careful management of details.

Guido van Rossum was working at **CWI (Centrum Wiskunde & Informatica)** in the Netherlands. He had previously worked with a language called **ABC**.

ABC had an important idea:

> Programming should be simple and readable.

Guido liked this idea, but ABC also had limitations. He wanted something that kept the **simplicity of ABC** while being more **powerful, extensible, and practical**.

So he started creating Python as a **hobby project during the Christmas holidays of 1989**.

The first public release came in **1991**.

### What did Guido want from Python?

He wanted a language where programmers could:

**1. Write programs easily**

Instead of requiring lots of complicated syntax, simple tasks should require simple code.

```python
print("Hello")
```

**2. Read other people's code easily**

Guido strongly valued readability.

If someone else wrote a program, you should be able to understand it without fighting through complicated syntax.

**3. Develop programs quickly**

The programmer shouldn't have to write huge amounts of boilerplate code just to accomplish a small task.

**4. Extend the language**

Python wasn't supposed to be a closed language. It was designed so that programmers could extend it with modules and components written in other languages such as C.

**5. Be useful for real-world problems**

Python wasn't created for only one specific field.

It was intended to be a **general-purpose programming language**.

---

### The deeper reason

The most important thing to understand is this:

Python wasn't created because **there were no programming languages**.

There were already many.

It was created because Guido wanted a better balance between:

**power + simplicity + readability + productivity**

That's the fundamental idea behind Python.

You can see this philosophy in one of Python's famous principles:

> **“Readability counts.”**

So when you eventually learn Python syntax, don't just ask:

> "What is the syntax?"

Also ask:

> **"Why did Python designers choose this syntax?"**

That question will help you understand Python much more deeply.
